# How to View the Statistics Examples

## Viewing the HTML File

1. **Download the file**: Download `statistics_examples.html` from this repository.

2. **Open in a web browser**: 
   - Double-click the HTML file, or
   - Right-click and select "Open with" your preferred browser (Chrome, Firefox, Safari, Edge, etc.)

3. **The page includes**:
   - Four statistical examples relevant to kinesiology
   - Data tables with clear formatting
   - Interactive charts using Chart.js
   - Statistical summaries for each example

## Examples Included

### Example 1: Sprint Performance
- 40-yard dash times before and after training
- Descriptive statistics (mean, median, standard deviation)
- Bar chart comparison

### Example 2: Vertical Jump by Position
- Basketball players' vertical jump data by position
- Statistical comparison across positions
- Colorful bar chart visualization

### Example 3: Heart Rate Recovery
- Heart rate measurements after maximal exercise
- Recovery percentage calculations
- Line chart showing recovery curve

### Example 4: Strength Training Progress
- Bench press progress over 12 weeks
- Comparison of two training methods
- Line chart showing progression

## Features

✓ **Fully responsive** - works on desktop, tablet, and mobile  
✓ **Print-friendly** - optimized CSS for printing  
✓ **Clear tables** - easy to read with alternating row colors  
✓ **Interactive charts** - hover over data points for details  
✓ **Professional styling** - uses modern CSS for better visibility  

## No Internet Required (After First Load)

The file uses Chart.js from a CDN. After the first load with internet access, the charts will be cached. Alternatively, you can download Chart.js for fully offline use.

Works with all modern browsers:
- Google Chrome
- Mozilla Firefox
- Microsoft Edge
- Safari
- Opera
