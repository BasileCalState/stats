# Statistics in Kinesiology - Examples

This repository contains statistical examples and datasets relevant to Kinesiology and Exercise Science. These examples are designed to help students understand how statistical methods are applied to analyze human movement, sports performance, and physical fitness data.

## Contents

### 1. Descriptive Statistics
- **File**: `01_descriptive_statistics.md`
- Learn how to calculate and interpret mean, median, mode, range, variance, and standard deviation using fitness assessment data

### 2. Correlation Analysis
- **File**: `02_correlation_analysis.md`
- Understand relationships between variables using athletic performance data
- Pearson correlation coefficient examples

### 3. Independent T-Test
- **File**: `03_independent_ttest.md`
- Compare two groups using different training methods
- Effect size calculation (Cohen's d)

### 4. One-Way ANOVA
- **File**: `04_anova.md`
- Compare multiple groups using different exercise programs
- Post-hoc testing

### 5. Linear Regression
- **File**: `05_linear_regression.md`
- Predict performance outcomes based on training variables
- Model interpretation

## Datasets

All datasets are located in the `data/` directory and include:
- `fitness_assessments.csv` - Body composition and fitness test results
- `athletic_performance.csv` - Sprint times, jump heights, strength measurements
- `training_study.csv` - Pre/post training intervention data
- `exercise_programs.csv` - Results from different exercise interventions

## How to Use These Examples

Each example file contains:
1. Research question or scenario
2. Description of the dataset
3. Step-by-step statistical analysis
4. Interpretation of results
5. Practice problems

## Prerequisites

Basic understanding of:
- Descriptive statistics
- Probability distributions
- Hypothesis testing concepts

Examples can be worked through using:
